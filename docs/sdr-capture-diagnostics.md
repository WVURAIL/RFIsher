# Retained SDR capture diagnostics

The CPU-only helpers in `src/rfisher_results/validation/sdr_capture.py` and the two `scripts/diagnose_sdr_*.py` drivers analyze archived development IQ without opening a device. The new release is `results/sdr_capture_diagnostics_2026-09-09/` in the workspace, or `../results/sdr_capture_diagnostics_2026-09-09/` from the RFIsher repository. Its README records the methods, exact windows, all original verdicts, additional failed RX-only evidence, numeric results and reproduction commands.

The retained strong 100 kHz smoke tones show joint-fit power changes of −0.000768 and −0.000735 dB when the narrow component near +309.9 kHz is included in a two-sinusoid fit. Six contiguous 5 ms blocks show projected-power ranges of 0.197 and 0.185 dB. These are finite-record diagnostics, not a physical received-power calibration, stationarity qualification or uncertainty interval.

The original seven-attempt plan and later RX-only amendment were frozen separately before their respective new payload analyses. All attempts and failed states remain visible. The added RX-only fragment contains the narrow component with before-readout TX-disable registers and no attempted TX stream/payload, but failed transport, a terminal drop-reporting chunk and missing after-readout registers prevent promotion to an accepted reference. TX-enabled zero guards in the smoke captures remain distinct from disabled controls.

The release is limited to the recorded smoke projector. No metadata binds the 2 MHz smoke capture to actual ATSC pilot/reference weights or calibrated complex spectral orientation. At a conditional RF=LO+offset convention, the component is near the nominal channel-19 pilot; its actual detector response must be measured before calling it irrelevant to those bins. The next hardware test should bind the intended channelization and weights to a complete, bracketed transmitter-disabled / TX-zero / known-signal sequence. Origin investigation is only relevant if the component changes the actual measured pilot/reference bins.
